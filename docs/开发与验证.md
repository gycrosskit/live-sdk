# Live SDK 开发与验证

从仓库根目录执行；第三方安装见 [README](../README.md)。需要 JDK、Android SDK 与 Xcode；最终 iOS Native 链接还需要真实 Kuikly Render Framework。

## 验证与归档

```bash
export ANDROID_HOME="$HOME/Library/Android/sdk"
bash scripts/verify.sh
# 指定真实原厂 Render Framework 后做 Swift 类型检查和 iphoneos 最终链接
LIVE_KUIKLY_IOS_FRAMEWORK_DIR=/path/to/parent/of/OpenKuiklyIOSRender.framework bash scripts/verify-ios-native.sh
```

脚本执行受影响 Android/iOS 编译、状态机/协议测试、staging Maven 消费、Android APK/D8、依赖无 Compose 检查与同时消费 CMP/Kuikly 的单 SDK 检查。[验证记录](验证记录.md)区分源码、编译、产物消费、最终链接和设备验收。

`archive-prebuilt.sh` 为 macOS 生成 Maven 归档，腾讯 SDK 仍使用原厂依赖；JitPack 在发布后校验 `release-checksums.txt` 中 immutable tag 的归档哈希，不在 Linux 临时编译 UIKit KLIB。预发布归档的校验值记录在 `release-checksums.txt`；当前候选远程消费使用 `-PremoteOnly -PliveVersion=0.2.1-rc.5`，该模式仅从 JitPack 读取本组件，排除 staging 与 mavenLocal。新版本门禁见 [rc.5 验收记录](0.2.1-rc.5远程发布验收.md)。


## 验收范围

构建、协议/状态机测试、发布产物消费与真实账号/设备业务验收分别记录。源码和独立远程消费已覆盖 Android APK/D8、iOS KLIB/Framework 与原生链接，设备画面、声音、进房、后台恢复仍需接入应用验收。HarmonyOS 无发布目标或 HAR，不运行也不承诺鸿蒙播放验收。

线程边界改动使用 `:live-core:testDebugUnitTest :live-core:iosSimulatorArm64Test :live-core:compileKotlinIosArm64` 定向验证。`AtomicLivePreviewControllerTest` 用独立 Main 调度器检查后台停止保持挂起、detach 完成后才放行下一 SDK 操作；`AtomicAudienceSessionTest` 检查退出后的入房成功不更新房间、仍离房清理，终态迟到事件不再次离房。调度器测试验证顺序契约，不能代替 Android Looper/UIKit 或真实腾讯账号设备验收。

2026-10-05 源码候选以 `--offline --max-workers=1 --no-parallel` 完成上述三项：Android XML 38 项、iOS Simulator XML 35 项，失败、错误、跳过均为 0，iOS arm64 编译成功。此结果不表示新版本已发布或宿主已消费。

## 独立 iOS 原生验证

```bash
bash scripts/verify-live-native-ios.sh
```

脚本在忽略的 `build/native-live-consumer` 生成纯 UIKit 工程，使用 CocoaPods 源码消费 `GycLiveNative` 并构建 `iphoneos arm64` App。消费源实现全部原生 callback/observer 并引用公开 API，最终链接实际 AtomicX/RoomEngine/IM 符号；不依赖 Shared、KMP、CMP 或 Kuikly。生成工程及缓存不进入 Git，厂商二进制不进入归档。独立 native Pod 链接不能替代应用 Shared 薄桥编译或设备会话验收。

`0.2.1-rc.1` 已发布 Git Pod 标签及源码 Release。上面的脚本是本地 path 验证；远程验收使用独立目录的消费工程，把 Podfile 的依赖改为 [接入指南](接入指南.md#ios-原生-cocoapod) 的 Git/tag 坐标后执行 `pod install` 和同样的 `iphoneos arm64` 最终链接。对比安装源码与标签内容，核验 tag 对应提交；CocoaPods 的 tag 来源 lock 不包含 `:commit` 字段，不能声称 lock 已打印提交。真实远程结果见 [验证记录](验证记录.md#021-rc1-原生-git-pod-远程结果)。Maven 仍使用 `0.2.0-rc.2`，不改变其 metadata 或校验值。

## M19 新候选

`0.2.1-rc.3` 同时更新 Maven 与原生 Pod；旧发布证据仍对应上述历史版本，新版本见 [M19 验证记录](M19验证记录.md)。改动契约见 [共享腾讯身份](共享腾讯身份.md)。定向命令：

```bash
bash gradlew :live-core:testDebugUnitTest :live-core:iosSimulatorArm64Test :live-core:compileKotlinIosArm64 --offline --max-workers=1
swiftc ios/Sources/GycLiveNative/LiveAccountOwnership.swift verification/ownership/main.swift -o build/ownership/live-ownership
build/ownership/live-ownership
# 直接编译生产 Account 文件，SDK替身驱动迟到callback与失败恢复
bash verification/ownership/verify-callbacks.sh
bash scripts/verify-live-native-ios.sh
```

纯 Swift 策略与生产 Account 回调契约已通过；后者直接编译生产文件到最小厂商替身，验证 own/borrow、pending reset、迟 logout、foreign 与失败/错误成功恢复，不代表厂商 ABI 或真实网络验收。Android/iOS/真实 Pod 与完整归档已通过，实际结果见 [M19 验证记录](M19验证记录.md)。


发布归档校验覆盖每个 POM 的 Apache-2.0 license、每个文件哈希和 `available-at` 对应的实际目标变体。空 CMP 资源 ZIP 可省略；有实际资源时脚本停止，不能直接移除资源变体。先运行 `python3 verification/publication/test_metadata.py`，再执行 `VERSION=0.2.1-rc.3 bash scripts/archive-prebuilt.sh`。rc.2 已发布但全变体远程检查未通过，不能作为此版验收证据。
