# 0.2.1-rc.5 远程发布验收

2026-10-05，Maven 预发行 `0.2.1-rc.5` 已发布，JitPack 制品审计通过。此版修复 Android/iOS KMP 预览停止的线程边界，并隔离退出后的 SDK 会话与互动回调。原生 Swift 源码、Podspec 与 Kuikly Swift View 未改，继续配套已验 Git Pod `0.2.1-rc.3`。HarmonyOS 实现维持暂停，无 OHOS target 或 HAR。

## API 与回调合同

- `AndroidLiveSdkRuntime` / `IosLiveSdkRuntime.stopActivePreview()` 保留 Main 同步入口；返回时当前预览已停止并 detach，后台调用会立即拒绝。
- Renderer/后台协程使用新增 `stopActivePreviewAndAwait()`，以 `withContext(Dispatchers.Main.immediate)` 等停止完成后再登录、重置或进房。iOS 全段包含 Swift 幂等停止；不使用阻塞等待连接 Main 与 Renderer。
- Android `AtomicXSession.isLoggedInAs` 要求 Main；`updateProfile` 切 Main 后再次校验当前账号。StateFlow 门禁仍允许任意线程访问，不代替预览停止。
- Android SDK 回调先到 Main 再校验释放状态；入房成功由共用状态机接纳后才更新 host 快照和绑定互动。被踢、退出或终态后的旧事件不能恢复页面；退出期间迟到入房成功仍执行 SDK 离房清理。
- iOS KMP observer 过滤资源释放后的快照/UI 事件。发送命令完成回调仍归原发起者，点赞成功使用原房间、原用户上报，宿主继续负责请求代次与超时。

## Kuikly 原厂仓库选择

合并远程消费者首次解析 `com.tencent.kuikly-open:core-render-android:2.28.0-2.0.21-ohos` 时，Gradle 从 Eazy 取得 POM/module，随后同源 AAR HEAD 返回 404，失败列表只搜索该仓库。原独立 live consumer 不含 Eazy，宿主也对 Eazy 设置版本过滤；不能用此前成功推断新增仓库顺序同样可用。

本轮实际 HTTP 复查中，Eazy 与腾讯 `maven-tencent` 的 POM/module/AAR GET 均返回 200，之后 AAR HEAD 也均为 200。实际 AAR 均为 934067 字节，SHA-256 `f1108225d64b225e53190a088516511c2eee359bbae2de0725eda27f4a9f7dc3`，与 metadata 内四种声明哈希匹配。因此已证明当次仓库选择和 HEAD 失败，尚不能证明永久缺制品，也没有服务器日志解释先 404 后 200 的原因。

安装配置只对 `com.tencent.kuikly-open` 使用 `exclusiveContent`，固定到 `https://mirrors.tencent.com/nexus/repository/maven-tencent/`，避免镜像已返回 metadata 后、Gradle 无法为缺失产物切源；其他 SDK 与插件仓库不改，库坐标和版本不改。公开响应、metadata 与哈希证明位于消费者忽略目录 `diagnose/kuikly-renderer-repository/`。
