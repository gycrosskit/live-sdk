# 0.2.1-rc.5 远程发布验收

2026-10-05，Maven 候选 `0.2.1-rc.5` 修复 Android/iOS KMP 预览停止的线程边界，并隔离退出后的 SDK 会话与互动回调。原生 Swift 源码、Podspec 与 Kuikly Swift View 未改，继续配套已验 Git Pod `0.2.1-rc.3`。HarmonyOS 实现维持暂停，无 OHOS target 或 HAR。

## API 与回调合同

- `AndroidLiveSdkRuntime` / `IosLiveSdkRuntime.stopActivePreview()` 保留 Main 同步入口；返回时当前预览已停止并 detach，后台调用会立即拒绝。
- Renderer/后台协程使用新增 `stopActivePreviewAndAwait()`，以 `withContext(Dispatchers.Main.immediate)` 等停止完成后再登录、重置或进房。iOS 全段包含 Swift 幂等停止；不使用阻塞等待连接 Main 与 Renderer。
- Android `AtomicXSession.isLoggedInAs` 要求 Main；`updateProfile` 切 Main 后再次校验当前账号。StateFlow 门禁仍允许任意线程访问，不代替预览停止。
- Android SDK 回调先到 Main 再校验释放状态；入房成功由共用状态机接纳后才更新 host 快照和绑定互动。被踢、退出或终态后的旧事件不能恢复页面；退出期间迟到入房成功仍执行 SDK 离房清理。
- iOS KMP observer 过滤资源释放后的快照/UI 事件。发送命令完成回调仍归原发起者，点赞成功使用原房间、原用户上报，宿主继续负责请求代次与超时。
