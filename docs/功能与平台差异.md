# 功能与平台差异

核对日期：2026-10-08。固定Git基线：`a02745b488eb6108b3b33a9904d5d31ddcfc0744`。适用发布：Maven 0.2.1-rc.12；未变GycLiveNative Git Pod继续0.2.1-rc.7，Kuikly Swift接线取本次Maven标签；OHOS仅core中立协议。固定Git基线用于追溯发布前增量；最终不可变tag与渠道消费结果见对应GitHub Release。历史验收保留原版本，设备/业务未验收范围不因发布而改变。

组件提供 Android/iOS 的腾讯 AtomicX 原生视频、预览、观看会话、账号门禁、互动和唯一快照。根模块是 CMP UI；`live-kuikly` 提供 raw View 与新增 KuiklyCompose UI；二者复用 `live-core`。业务账号/UserSig、品牌资料、直播间 ID、准入、业务点赞上报和页面控件由宿主提供。OHOS 直播按本轮要求排除；中立表情协议 KLIB 不能证明 OHOS 音视频实现。

## 公开功能与合同

- CMP `LivePreview`/`LiveCoreView` 和 Kuikly raw/Compose均复用现有native/core。已发布raw DSL为 `io.github.gycrosskit.livesdk.LiveVideo(init)`；`io.github.gycrosskit.livesdk.kuikly.LiveVideo(liveId, preview=false, active=true, modifier, onEvent, onController)` 会下发同房间active变化；普通重组不重复提交room，以免重开explicitRelease。移除先关事件归属再release；更换controller callback只交接句柄。
- 预览需active、visible/宿主STARTED、sessionReady等门禁均满足；COVER/LOADING/PLAYING/FAILED由真实平台回报。观看与列表预览互斥；全局队列join/leave等待和超时由core维持，不新建第二SDK会话。
- `sendBarrage`/`like`/`toggleFollow`/`refreshAudience`、快照与join/kicked/end/禁言等事件按会话代次归属。messages含sequence/timestamp/sender/content/businessId/data/kind；sequence不能单独当全局唯一ID。业务点赞上报、文案本地化和消息UI由宿主消费。
- `AndroidLiveSdkRuntime`/`IosLiveSdkRuntime`门禁不自行生成UserSig或代替真实登录。iOS需安装宿主bridge；关闭账号资格并停止预览后再清账号，共用IM身份的借用/自有规则须与客服串行协调。
- 点赞共同能力不等于相同UI入口：`like()`发起命令，已注入native reporter在SDK确认成功后报告批次数；snapshot的likeEffectSequence只服务效果触发，不能当业务上传ACK。`LiveLikeBatcher`是core内部实现，不是UI公开参数。[Android原生注入](../live-kuikly/src/androidMain/kotlin/io/github/gycrosskit/livesdk/GycLiveView.kt)、[Swift原生注入](../live-kuikly/ios/GycLiveView.swift)、[iOS Controller](../live-kuikly/src/iosMain/kotlin/io/github/gycrosskit/livesdk/IosKuiklyLiveController.kt)。
- Main同步 `stopActivePreview` 与Renderer可挂起 `stopActivePreviewAndAwait` 不可互换。不要阻塞Renderer/Main互等。
- PiP `accepted`只表示平台请求受理/实验接口提交，不表示浮窗可见；真实状态须宿主回报。iOS实验接口、AndroidActivity PiP、应用内小窗是不同接线，不能用共同snapshot当视觉证据。

## 差异分类与使用边界

| 分类 | 当前合同与限制 |
| --- | --- |
| 组件接口 | CMP typed state/callbacks与Kuikly raw/controller/event不同；Composable补齐声明更新与释放接线，不复制会话状态机。CMP LiveCoreView有likeReporter参数；Kuikly raw/Composable没有同名prop，Android在注册工厂创建GycLiveView后设置likeReporter，iOS在Swift GycLiveView创建后设置likeReporter并交给IosKuiklyLiveController，必须在创建观看会话前完成。两端默认None。 |
| OS/SDK边界 | Android AtomicX与iOS AtomicXCore/RoomEngine是不同版本SDK；PiP系统接口/实验接口语义不同，accepted不等于可见。 |
| 宿主输入 | 账号、SDKAppId、UserSig、房间、nickname/avatar、业务点赞、页面生命周期与真实PiP回报必须由宿主下发。相同房间active变更不能只写在viewInit。 |
| 排除 | OHOS直播本轮不纳入；中立协议KLIB不提供AtomicX平台视频，不能用协议编译判音视频支持。 |
| 未验收 | 两renderer真实音画、SDK/cloud进出房、后台硬件释放、弱网重连、实际PiP及vendor权限未本轮业务验收。 |
